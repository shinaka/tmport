# Code segment `1000` (TMTWINCD.EXE, NE segment 1) — Borland C++ 4.x runtime library

Scope: every byte of Ghidra selector `1000` (NE segment 1, file offset `0x800`, length `0x3BD4`
= 15 316 bytes, flags `0x1D50`: code, moveable, preload, discardable, has relocations).

Evidence used: `re/win/ghidra_export/{functions.tsv,disassembly.asm,functions/1000_*.c}`, a
re-disassembly of the parts Ghidra had not turned into functions (my Ghidra script
`extracted/scratch/code_1000/scripts/DumpSeg1000.java` run on a *copy* of the project, output
`extracted/scratch/code_1000/listing1.txt`), the raw NE segment/relocation tables of
`TMTWINCD.EXE` (`extracted/scratch/code_1000/{ne.py,relocs.py,relocs_all.txt}`) and the
DGROUP (`11b8`) image at file offset `0x23C00`.

Notation: **[O]** = observed directly in bytes/disassembly; **[I]** = inference (usually "this
matches the well-known Borland RTL routine X"). Addresses are `selector:offset`;
`11b8:XXXX` is DGROUP offset `XXXX` (file offset `0x23C00+XXXX`).

---

## 1. Summary

* **[O]** Segment `1000` contains **no game logic at all**. It is the packed Borland C++ 4.x
  (1993-94) large-model Windows runtime: the `C0W` startup code, exit/atexit, long-integer
  helpers, the far heap (`malloc`/`new` on top of `GlobalAlloc`), low-level DOS file I/O,
  a minimal stdio, `printf` engine (`sprintf`), string/memory functions, `rand`, `setjmp`/
  `longjmp` (via `Catch`/`Throw`), signals/abort/error boxes, and the C++ support classes
  `xmsg`/`xalloc` (+ destructors for `string::lengtherror`/`string::outofrange`, whose
  `string` class lives in `11a8`). Exception-handling *engine* code is in `11a0` (other doc).
* Each Borland RTL `.obj` keeps its own code; the linker packed ~35 modules into this one
  physical segment, so the "one segment = one source module" rule does **not** hold here.
* Ghidra knew 139 functions; I identified 36 more entry points / alternate entries
  (e.g. `N_LDIV@`, `_cexit`, `_setargv`, `setvbuf`, `xmsg::xmsg`, `raise`), plus the
  code-segment data (RTTI type descriptors, exception-frame tables, switch tables). **Every
  byte of the segment is now accounted for** (see §13).
* What a re-implementation must preserve (game-visible behaviour):
  1. `rand()`/`srand()` exact LCG and the game's inline `random(n)` idiom (§5);
  2. `sprintf` semantics for `%s` and `%lu` (the only formats the game uses, §9);
  3. file-open modes used for the user file (§8), `mkdir`;
  4. `_argc/_argv` parsing (game reads `argv[1][0]`, §4.3);
  5. `setjmp`/`longjmp` used as a game-level non-local exit (§10);
  6. `_ctype` table contents (game code tests `_ctype[c+1] & 0xDE` inline, §11);
  7. fatal-error behaviour (message box + exit code) for out-of-memory/abort (§6, §12).
  Everything else can be replaced by the host C/C++ library.

## 4. Startup, command line and shutdown

### 4.1 `entry` (`1000:0000`) — Borland `C0W` [O]

Register contract from the Windows loader: BX = stack size, CX = heap size, DI = hInstance,
SI = hPrevInstance, ES = PSP. Sequence:

1. Preserve BX/CX/ES, `push 0; call far 11a0:04e7` (exception-runtime init, see `code_11a0`;
   it calls `__initExeTaskData` `1000:2e99` because SS==DS).
2. `KERNEL.InitTask` (ordinal 91). AX==0 → `exit(255)` via `1000:00d9`.
3. `SS:[0014] = 0xFFFF` (exception context "none").
4. Store InitTask results: `11b8:0038` = ES (cmd-line selector), `11b8:003e` = BX (cmd-line
   offset), `11b8:003c` = SI (hPrev), `11b8:003a` = DI (hInstance), `11b8:0040` = DX (nCmdShow).
5. Zero BSS: `rep stosb` from `11b8:3880` for `0x66A2-0x3880` bytes. **Every DGROUP variable at
   offset ≥ `0x3880` starts as zero** (useful for all other agents).
6. `KERNEL.WaitEvent(0)`, `USER.InitApp(hInstance)`; failure → `exit(255)`.
7. `INT 21h AH=30h` → `11b8:0042` (DOS version).
8. `KERNEL.GetWinFlags`: bit `0x0001` (WF_PMODE) → `11b8:0032 = 8`; bit `0x0400` (WF_80x87)
   → `11b8:0036 = 1`; `(flags & 0x0E) >> 1` → if result has bit 2 keep (486 → 4) else if
   non-zero add 1 (286 → 2, 386 → 3) → `11b8:0034`.
9. Run the `#pragma startup` table `11b8:3862..3879` with `c0_StartupRun` (`1000:00e8`).
10. `WinMain(hInstance, hPrevInstance, lpCmdLine, nCmdShow)` = **`far call 1010:0000`**.
11. `exit(AX)`.

### 4.2 Startup / exit records [O]

Record = 6 bytes: `u8 kind` (0 = near proc in segment 1000, 1 = far proc, 0xFF = already run),
`u8 priority`, `u16 offset`, `u16 segment` (relocated; ignored for near).

| DGROUP | kind | prio | Target | Routine |
|---|---|---|---|---|
| `3862` | far | `0x20` | `1000:06ad` | construct static `__xalloc` |
| `3868` | near | `0x02` | `1000:08fa` | `_setupio` |
| `386e` | far | `0x0A` | `1000:2fb8` | `_setargv` |
| `3874` | far | `0x09` | `1000:32aa` | `_setargv0` |
| `387a` (exit) | far | `0x20` | `1000:0703` | destroy `__xalloc` |

`c0_StartupRun` repeatedly scans the table for the not-yet-run record with the **smallest**
priority (strict `<`, so ties go to the earlier record), marks it 0xFF, calls it. Effective
order: `_setupio` (2) → `_setargv0` (9) → `_setargv` (10) → `__xalloc` init (0x20).
`c0_ExitRun` (`1000:012c`) picks the **largest** priority (`>=`, ties go to the later record).
[O] There are no game static constructors: the game has no global C++ objects with ctors.

### 4.3 Command line: `_setargv0` / `_setargv` [O]

`_setargv0` (`1000:32aa`): `_argv0 (11b8:36ea) = malloc(0x51)`; NULL → `_ErrorExit("Out of memory
in _setargv0" (11b8:36ee), 3)`; `GetModuleFileName(hInstance, _argv0, 0x50)`.

`_setargv` (`1000:2fb8`), locals: 80-byte `cmd` (bp-0xB0), 80-byte `path` (bp-0x60):
1. If `*lpCmdLine != 0`: copy bytes into `cmd` until CR (0x0D) or NUL, terminate. **No length
   check** (a command line > 79 chars overflows into `path`; harmless in practice).
2. `_argc = _argv = capacity = 0`; `strcpy(path, _argv0)`; `__addarg(path, copy=1)` → argv[0].
3. If a command line exists: skip leading space/tab; `buf = malloc(strlen(rest)+1)` (NULL →
   `_ErrorExit("No space for copy of command line" 11b8:367a, 3)`); then loop: skip spaces/tabs;
   copy one argument into `buf` until space/tab/NUL, where a `"` starts a quoted run (spaces kept)
   ending at the next `"`; inside or outside quotes `__argcopychar` turns the 2-char sequence
   `\"` into `"`; NUL-terminate; `__addarg(start, copy=0)` (points into `buf`).
4. `__addarg(NULL, 0)` (terminating NULL), `_argc--`, `free(_argv0)`, `_argv0 = argv[0]`.

`__addarg` (`1000:31eb`): if `_argc == capacity` grow by 16 entries with `realloc(_argv,
cap*4)` (NULL → `_ErrorExit("No space for command line argument vector", 3)`); if `copy` →
`malloc(strlen+1)` (NULL → `_ErrorExit("No space for command line argument", 3)`) + `strcpy`;
`_argv[_argc++] = p`.

Game use [O]: `1018:086d` checks `_argc > 1` and `argv[1][0] == '3'` or `'4'`, then writes an INI
value (see the doc covering `1018`).

### 4.4 Shutdown: `exit`, `_exit`, `_cexit`, `_c_exit` [O]

`__exit(code [bp+4], dontexit [bp+6], quick [bp+8])` (`1000:021d`, near, `ret 6`):

```
if (!quick) {
    if (DS != SS) {                      // DLL case only
        if (GetModuleUsage(hInstance) > 1 || __exitCleanupDone) goto skip;
    }
    __exitCleanupDone = 1;               // 11b8:2e10
    while (_atexitcnt) _atexittbl[--_atexitcnt]();   // LIFO, far calls
    _cleanup();                          // #pragma exit table
    _exitbuf();                          // default no-op; _xfflush after setvbuf
}
skip:
_checknull(); _restorezero();            // both empty
if (!dontexit) {
    if (!quick) { _exitfopen(); _exitopen(); }   // _exitopen = _xclose once open() was used
    _terminate(code);                    // INT 21h AH=4Ch
}
```
`exit(c)` = `__exit(c,0,0)`; `_exit(c)` = `__exit(c,0,1)`; `_cexit()` = `__exit(0,1,0)`;
`_c_exit()` = `__exit(0,1,1)`. `atexit` (`1000:0198`) keeps up to 32 far pointers at
`11b8:6600`, returns 1 when full.

## 5. Random numbers — `rand` / `srand` and the game's `random(n)` idiom

[O] `srand(seed)` (`1000:0842`): `__randSeed (u32 at 11b8:3044) = seed` (high word 0).
[O] `rand()` (`1000:0859`):

```
uint32_t __randSeed = 1;                       // initial value in DGROUP
int rand(void) {
    __randSeed = __randSeed * 0x015A4E35u + 1u;  // mod 2^32 (N_LXMUL@)
    return (int)((__randSeed >> 16) & 0x7FFF);
}
```
Test vectors: seed 1 → 346, 130, 10982, 1090, 11656, 7117; `srand(0)` → 0, 346, 130, 10982;
`srand(0x1234)` → 8151, 11177, 8835, 19970.

[O] Seeding: `1118:0000` calls `srand(timeGetTime())` (16-bit argument → low word of the
millisecond tick) inside its main loop, before each game (re)start.

[O] Callers never use `rand() % n`; every site compiles Borland's `random(n)` macro with 386
instructions, e.g. `1110:0102`: `CWDE; IMUL EAX,EAX,0x19C; MOV EBX,0x8000; CDQ; IDIV EBX`:

```
int random(int n) { return (int)(((long)rand() * n) / 32768); }   // range 0..n-1
```
Other forms seen: `rand()*[DAT]`/`0x8000`, `rand()<<2 / 0x8000` (= random(4)),
`rand()*1000/0x8000`, `rand()*5/0x8000`, `rand()*(k+1)/0x8000`. A re-implementation that wants
identical sequences must use this LCG, this scaling and seed with a 16-bit value.

## 6. Memory management

### 6.1 `new`, `delete`, new-handler, `xalloc` [O]

* `operator new(size)` (`1000:05f1`): `if (size == 0) size = 1; for (;;) { p = malloc(size);
  if (p || !_new_handler) return p; _new_handler(); }`.
* `_new_handler` (`11b8:3032`, far ptr) initially = `__default_new_handler` (`1000:055c`) which
  **throws** a copy of the static `xalloc __xalloc` (`11b8:302c`, message "Out of memory"
  `11b8:3036`, size 0) via `11a0:1689` with type descriptor `1000:0762`. Unless caught, the
  exception runtime ends in `abort()` → message box "Abnormal program termination", exit code 3.
* `set_new_handler(h)` (`1000:05c3`) swaps the pointer.
* `operator delete(p)` (`1000:01ca`) = `free(p)`; `delete[]` (`1000:01e4`) → `operator delete`.

### 6.2 `malloc` family (Windows global heap sub-allocator) [O]

Public: `malloc(n)` `1000:3abe`, `calloc(n,s)` `3afc`, `realloc(p,n)` `3ada`, `free(p)` `3b1d`;
each passes `_WinAllocFlag` (`11b8:0045`, initial 0) as the extra GlobalAlloc flag word to
`_mallocflags`/`_callocflags`/`_reallocflags`/`_freeflags` (`3608/364f/36fb/36c9`), which put it
in `11b8:0045` temporarily and call the core.

`__farmalloc_core` (`1000:33c7`, size in DX:AX, result ES:DI and DX:AX):
1. If `flags & ~(GMEM_ZEROINIT 0x40 | GMEM_SHARE 0x2000)` ≠ 0, or `size+7` overflows 16 bits →
   **direct block**: `GlobalAlloc(GMEM_MOVEABLE | (SS!=DS ? GMEM_SHARE : 0), size)` +
   `GlobalLock` (`__GlobalAllocLock` `1000:3a58`); pointer offset is 0.
2. Else `need = (size + 7) & ~3` (4-byte header + rounding). Walk the segment list (descriptor
   `11b8:669c`: `far ptr first; u16 count`) and try `__segAllocBlock` (`1000:34c9`) on every
   segment whose free-byte count (`+0x0C`) ≥ need. `__segAllocBlock` walks the free list, merges
   each free block with an immediately following free block, takes the first block that is big
   enough, and carves the allocation from its **tail** (exact fit: unlinks the block); returns
   CF=1 and ES:DI = user pointer on success.
3. None fits → new heap segment: size `0x1000` if `need ≤ 0x0FF0`, else `(need + 0x10F) & 0xFF00`
   (if that overflows → direct block); link it at the list head and allocate from it.

Heap segment header [O]: `+0 far next`, `+4 far prev`, `+8 u16 segment size`, `+0x0A u16 free
list head (near)`, `+0x0C u16 free bytes (= size-0x10 initially)`, `+0x0E` first free block;
the last word of the segment is a 0 sentinel. Free block: `u16 size+1` (odd = free), `u16 next`
(near). Used block: `u16 size` (even, includes the 4-byte header), `u16 offset of the segment
header` (0), then user data (user pointer = block+4). `__blockSize` (`1000:3531`) returns
`[p-4]-4`, or `GlobalSize` for offset-0 pointers.

`__farfree_core` (`1000:3547`): offset 0 → `GlobalFree`; else adds the block back to its segment
free list (sorted by address); if the segment becomes completely free and the heap has more than
one segment it is unlinked and freed. `_callocflags` ORs `GMEM_ZEROINIT` and additionally
`_fmemset`s results whose total is < 0xFFFF (sub-allocated blocks are not zeroed by Windows).
`_reallocflags`: `p==NULL` → malloc; `size==0` → free, return NULL; direct block → `GlobalReAlloc
(…, GMEM_MOVEABLE|flags)`; otherwise malloc + copy `min(old,new)` + free.

Re-implementation: use the host allocator; nothing in the game depends on this layout.

## 8. Low-level file I/O (used for the user file)

Handles index `_openfd` (`11b8:2fa4`, 20 words, `_nfile` = 20 at `11b8:2fa2`). Flag bits
([O] from code): `O_RDONLY 0x0001`, `O_WRONLY 0x0002`, `O_RDWR 0x0004`, sharing `0x00F0`,
`O_CREAT 0x0100` (in `_openfd`: "writable"), `O_TRUNC 0x0200` (in `_openfd`: EOF-seen),
`O_EXCL 0x0400`, `O_APPEND 0x0800`, `0x1000` changed/created, `O_DEVICE 0x2000`,
`O_TEXT 0x4000`, `O_BINARY 0x8000`. Initial table: `6001 6002 6002 A004 A002` for handles 0-4.

`open(path, access, mode)` (`1000:1495`) [O]:
```
if (!(access & 0xC000)) access |= _fmode & 0xC000;          // _fmode = 0x4000 (text)
e = errno; attr = _rtl_chmod(path, 0); errno = e;          // -1 if file absent
if (access & O_CREAT) {
    mode &= _notUmask;                                     // 0xFFFF
    if (!(mode & 0x0180)) __IOerror(1);                    // (continues)
    if (attr == -1) {
        if (_doserrno != 2) return __IOerror(_doserrno);
        attr = (mode & 0x0080) ? 0 : 1;                    // read-only if no S_IWRITE
        if (access & 0x00F0) { fd = __creat(0, path); if (fd < 0) return fd; _rtl_close(fd); goto do_open; }
        fd = __creat(attr, path); goto set_flags;          // INT 21h AH=3Ch
    }
    if (access & O_EXCL) return __IOerror(0x50);           // EEXIST
}
do_open:
fd = _rtl_open(path, access);         // INT 21h AH=3Dh, AL = (WRONLY?1:RDWR?2:0) | (access&0xF0)
if (fd >= 0) {
    dev = ioctl(fd, 0);
    if (dev & 0x80) { access |= O_DEVICE; if (access & O_BINARY) ioctl(fd, 1, (dev & 0xFF) | 0x20); }
    else if (access & O_TRUNC) __trunc(fd);                // write 0 bytes
    if ((attr & 1) && (access & O_CREAT) && (access & 0xF0)) _rtl_chmod(path, 1, 1);
}
set_flags:
if (fd >= 0) {
    _exitopen = _xclose;                                    // 1000:0ea4
    _openfd[fd] = (access & 0xF8FF) | ((access & 0x0300) ? 0x1000 : 0) | ((attr & 1) ? 0 : 0x0100);
}
return fd;
```

Game usage ([O] `1040`): `1040:0015` = `open(path, 0x8302, 0x0180)` → O_BINARY|O_TRUNC|O_CREAT|
O_WRONLY, S_IREAD|S_IWRITE (create/overwrite for saving); `1040:0039` = `open(path, 0x8001)` →
O_BINARY|O_RDONLY (loading); `1040:005a` → `read` (via `1000:1baf`), `1040:007e` → `write`
(via `1000:208e`), `1040:00a2` → `close`, `1040:0000` → `mkdir`.

Read/write semantics ([O]): `read` (`1ae2`): `h ≥ _nfile` → EBADF(6); `n==0 || n==0xFFFF` → 0;
EOF bit set → 0; `_rtl_read` (EACCES if write-only, INT 21h AH=3Fh); binary handles return the
raw count; text handles strip CR, and at `^Z` (0x1A) seek back so the file pointer rests on the
`^Z`, set EOF bit and return the bytes before it. `write` (`1ea4`): EBADF/zero-length as above;
`O_APPEND` → `lseek(h,0,SEEK_END)`; binary → `_rtl_write` (EACCES if `O_RDONLY`; INT 21h AH=40h;
sets `0x1000`); text → LF→CRLF through a 128-byte stack buffer; returns the number of *source*
bytes consumed (or -1). `lseek` (`04f2`) clears the EOF bit. `close` (`0f82`): EBADF check,
`_openfd[h]=0`, INT 21h AH=3Eh. `mkdir` (`0522`): INT 21h AH=39h, 0/-1. `_xclose` (`0ea4`, run at
exit) closes handles 2.._nfile-1. Errors go through `__IOerror` (`03e8`): DOS error 0..0x58 →
`_doserrno = e; errno = _dosErrorToSV[e]` (table `11b8:2fd2`, values ≥ 0x59 → 0x57); a negative
argument `-x` with `x ≤ _sys_nerr` sets `errno = x, _doserrno = -1`; always returns -1.

Re-implementation: binary `fopen("wb")`/`fopen("rb")` equivalents, create the directory if
missing; no text translation is ever involved for the user file.

## 9. `sprintf` / `__vprinter`

`sprintf(buf, fmt, ...)` (`1d19`) sets `*buf = 0` and calls `__vprinter(__strputn, &buf, fmt,
&args)`; `vsprintf` (`1d40`) is the same with an explicit `va_list`. `__strputn` (`1cd4`) copies
each chunk, advances the output pointer and keeps the output NUL-terminated. Return = number of
characters produced, or -1 if the putter returned 0.

`__vprinter` (`09e2`/`0a46`) [O]: output is staged in an 80-byte stack buffer, flushed through
the putter when full and at the end. Format grammar: `%` `[flags]` `[width]` `[.prec]` `[size]`
`conv`, where the class of every character 0x20..0x7F comes from the table `11b8:3151` and is
dispatched through the jump table `1000:0e73` (24 entries):

| Class | Chars | Action |
|---|---|---|
| 0 | space, `+` | sign character (a `+` is never overwritten by space) |
| 1 | `#` | alternate form |
| 2 | `*` | width or precision taken from the next int argument (negative width ⇒ left-justify) |
| 3 | `-` | left-justify |
| 4 | `.` | start precision |
| 5 / 9 | `1`-`9` / `0` | width/precision digits; leading `0` ⇒ zero padding |
| 6 / 7 / 8 | `l` / `L` / `h` | long (reads 2 words) / long double / short |
| 0x16 / 0x17 | `N` / `F` | near / far pointer argument for `%s %p %n` |
| 0x0A | `d i` | signed decimal |
| 0x0B / 0x0C / 0x0D | `o` / `u` / `x X` | octal / unsigned decimal / hex (lower/upper digits) |
| 0x0E | `p` | pointer `SSSS:OOOO` (far) or `OOOO` (near), uppercase hex |
| 0x0F | `e f g E G` | through hook `11b8:385a` → stub `1000:2a7e` "floating point formats not linked" (fatal) |
| 0x10 / 0x11 / 0x12 | `c` / `s` / `n` | char / string (NULL prints `(null)` `11b8:314a`, precision limits length) / store count |
| 0x13-0x15 | anything else | the whole `%...` sequence is copied literally |

`%%` emits `%`. Numbers are converted by `__longtoa(value, buf, radix, signed, hexbase)` (`0452`:
repeated division, radix 2..36, `-` prefix for negative signed values).
**Game usage** ([O] format strings in DGROUP): only `%s` (`11b8:09d6`, `09d9`, `0fe8`, `2106`,
`2143`) and `%lu` (`11b8:0fee`, a score total). The `0xFF ...` bytes inside those strings are the
game's own text-markup codes (not printf).

## 10. `setjmp` / `longjmp` [O]

`jmp_buf` (≥ 0x18 bytes): `+0x00..0x11` Windows `CATCHBUF` (9 words), `+0x14` saved exception
context (`SS:[0014]`), `+0x16` word (set to 0).
* `setjmp(jb)` (`32e5`): `jb+0x14 = SS:[0014]`; calls `11a0:34e7(ctx)`; `jb+0x16 = 0`; tail-jumps
  to `KERNEL.Catch(jb)` (returns 0 directly, or the `longjmp` value).
* `longjmp(jb, val)` (`3309`): if `jb+0x14 != SS:[0014]` → `11a0:18ba(...)` (run pending
  destructors/unwind) and restore `SS:[0014]`; `r = 11a0:34e7(ctx)`; if `r != -1 && r !=
  jb+0x16` → `11a0:25b4(...)`; `if (val == 0) val = 1`; `KERNEL.Throw(jb, val)`.
* Game [O]: the only `jmp_buf` is `11b8:5eda`, exactly 0x18 bytes (the next DGROUP variable
  the code references is `5ef2`). `1118:004c` does `r = setjmp(DS:5eda)` once, before its main
  loop; `r == 2` → `1118:03eb` (shutdown sequence, function returns 0 to WinMain). There are
  **two** `longjmp` sites (corrected per ARCHITECTURE.md §7.1 C7; an earlier version of this
  section said there was only one and called the restart branch unreachable):
  * `1140:008c: longjmp(DS:5eda, 2)` = Exit. It is reached from `1140:00bb` (`MenuCmd_Exit`,
    after the Yes/No box `10c0:0ae5(DS:1533) == 1` plus clean-up calls) and from `1160:04f6`
    (sign-in exit prompt). So value 2 = "quit the game from any depth".
  * `1140:0062: longjmp(DS:5eda, 1)` = Start Another Game (menu handler, not a Ghidra function;
    bytes at file 0x16A62: Yes/No box `DS:14d6`, then hint := −1, music stop, `longjmp(5eda, 1)`).
    Value 1 takes the `r != 0 && r != 2` restart branch at `1118:0077..`, which is therefore
    **reachable**: it frees the climb state and re-enters the Club Sign-In.
  Re-implement with C++ exceptions (restart / quit) that unwind to the main loop; quit then runs
  the `1118:03eb` shutdown sequence.

All far-pointer (large model) versions; byte comparisons are **unsigned**:

`setmem` `1394`), `memmove` (`1439` → `movmem` `13e0`, copies backwards when src < dst),

## 12. Fatal errors, abort, signals [O]

* `__ErrorMessage(msg)` (`2f3c`): caption = text after the last `\` of `_argv0` (whole string if
  none); `MessageBox(NULL, msg, caption, modality | MB_ICONHAND(0x10))`, where `modality` =
  `MB_TASKMODAL 0x2000` if `EnumTaskWindows(GetCurrentTask(), __taskHasWindowProc)` found a
  window, else `MB_SYSTEMMODAL 0x1000` (`__msgBoxModality` `2f05`). `_ErrorMessage` (`01fe`) is a
  far wrapper; `_ErrorExit(msg, code)` (`2f94`) = message box + `_exit(code)`.
* `abort()` (`0186`) = `raise(SIGABRT=22)`; if that returns, `_abort()` (`016e`) = message
  "Abnormal program termination" (`11b8:2de2`) + `_exit(3)`.
* `signal(sig, h)` (`381d`) / `raise(sig)` (`397d`): six signals `{2,4,8,11,15,22}`
  (`11b8:372a`), handlers `11b8:3712` (far ptrs, 0 = SIG_DFL, 1 = SIG_IGN, -1 = SIG_ERR), extra
  argument per signal `11b8:3730` = `{0,0x15,0x8C,0x0B,0,0}`. `raise`: unknown → 1; SIG_IGN → 0;
  SIG_DFL → SIGFPE: `_fperror(0x8C)`, others `__sigdefault`; user handler → reset to SIG_DFL then
  `h(sig, extra)`.
* `__sigdefault` (`38fe`, table `1000:3965`): SIGINT → `INT 23h`; SIGILL "Illegal Instruction",
  SIGFPE "Floating Point Trap", SIGSEGV "Segment Violation", SIGTERM "Program Terminated" →
  `_ErrorExit(…, 1)`; SIGABRT "Program Aborted" → `_ErrorExit(…, 3)`; other → "Abnormal Program
  Termination", exit 1.
* `_fperror(code)` (`3874`): "Floating Point: " + reason for codes 0x81 Invalid, 0x82 DeNormal,
  0x83 Divide by Zero, 0x84 Overflow, 0x85 Underflow, 0x86 Inexact, 0x87 Unemulated, 0x8A Stack
  Overflow, 0x8B Stack Underflow, 0x8C Exception Raised (0x88/0x89/other keep the preset
  "Square Root of Negative Number"); `_ErrorExit(11b8:3736, 3)`. `__fpsignal` (`3a01`) routes FP
  exceptions to the SIGFPE handler; no caller found.
* `perror(s)` (`168e`) writes to stderr (unused by the game as far as known).

Re-implementation: show an error dialog/log and exit with the same codes (3 for out-of-memory /
abort paths) if fidelity matters; otherwise ordinary fatal error handling.

## 17. Open questions

1. `11a0:0000`'s 32-bit counter (`SS:0010`) is incremented by every RTL ctor and decremented by
   every dtor; its consumer is in `11a0` (exception runtime). Its exact role (BC4 "live object
   count" for `-xd` cleanup?) is inferred, not verified.
2. `1000:2a7e` (float-format stub) is entered by a *near* call from `__vprinter` but then makes a
   near call to the far routine `_ErrorExit` with only an offset pushed, so the message pointer/
   exit code it would use look wrong. The path is unreachable for this game (no `%e/%f/%g`), so it
   was not pursued.
3. The three empty functions `1000:2682`, `26e4`, `27b8` have no references (only segment-only
   relocations that point at "segment 1000"); presumably empty inline functions emitted
   out-of-line. Harmless.
4. `__fpsignal` (`1000:3a01`) and `__heapReset` (`1000:3370`) have no known callers (could be
   reached through pointers in code not yet disassembled in other segments).
5. `jmp_buf` bytes `+0x12..0x13` are not touched by `setjmp` (purpose unknown, possibly
   padding). Resolved: the game's buffer `11b8:5eda` is 0x18 bytes (§10).
6. `1000:1baf` / `1000:208e` are bare `JMP read` / `JMP write` alias entries; which Borland
   public names they carry (`__read`/`__write`?) is unknown and irrelevant for behaviour.
7. The first-call order of `_ExceptInit` (`11a0:04e7`, before `InitTask`) relative to the
   per-task data is documented from code; details belong to `code_11a0`.
